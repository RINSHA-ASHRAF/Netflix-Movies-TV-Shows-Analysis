# 🎬 Netflix Movies and TV Shows Analysis

## 📌 Project Overview

This project explores Netflix's Movies and TV Shows dataset through Exploratory Data Analysis (EDA). The aim is to understand the content available on Netflix and identify meaningful patterns and trends using Python.

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Explore content release trends over the years.
- Identify the countries producing the most Netflix content.
- Analyze popular genres and content ratings.
- Explore movie durations and TV show seasons.
- Examine Netflix content additions over the years.
- Identify directors with the highest number of titles.

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Google Colab** – Development environment

## 📈 Key Findings

- Movies account for approximately 69.6% of the titles, while TV Shows account for approximately 30.4%.
- The United States contributes the highest number of Netflix titles, followed by India and the United Kingdom.
- Netflix content additions increased significantly from 2016 onwards, with 2019 showing the highest number of additions in the analyzed period.
